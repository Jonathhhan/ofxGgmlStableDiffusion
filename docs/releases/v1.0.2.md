# ofxGgmlStableDiffusion 1.0.2

Release date: 2026-06-07

`ofxGgmlStableDiffusion` 1.0.2 keeps the addon on the stable-diffusion.cpp wrapper lane while aligning it with the shared `ofxGgmlCore` runtime-provider path.

## Highlights

- Uses `ofxGgmlCore` as the default ggml/runtime provider, with the bundled ggml fallback still available for compatibility and bisecting.
- Updates the native stable-diffusion.cpp source snapshot to upstream release `master-666-7948df8`.
- Adds split-model Wan video workflow support in the video example, including saved diffusion, UMT5/T5XXL, and VAE paths.
- Adds model-family-specific video defaults for Wan 2.1 T2V 1.3B, including resolution, frame count, FPS, steps, CFG, and strength.
- Improves video saving with upstream `.webp` and `.webm` media export when media libraries are staged, plus a local `.avi` MJPEG fallback.
- Keeps example cancellation behavior available during both context loading and generation.
- Repairs partially generated Visual Studio projects in ProjectGenerator smoke tests when the legacy generator exits after writing the `.vcxproj`.
- Expands validation to 22 CMake test executables, including video export regression coverage and example compile checks.
